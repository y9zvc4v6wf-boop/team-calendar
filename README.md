# Planning Équipe - Web App iOS

Déposer tous les fichiers et le dossier `icons` à la racine du même hébergement HTTPS.

## Installation iPhone
1. Ouvrir le site dans Safari.
2. Utiliser Partager.
3. Choisir Sur l’écran d’accueil.
4. Activer Ouvrir comme app, puis Ajouter.

Le service worker est actif uniquement en HTTPS ou sur localhost. Les données Firebase restent en ligne.
